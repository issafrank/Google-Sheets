# Google Sheets Projects

Repository ng Apps Script projects para sa Google Sheets.

## Projects

- **[Radio-Inventory](./Radio-Inventory/)** — Inventory & Maintenance system para sa radio assets (asset master, issuance, maintenance, audit, return forms + dashboard).

## Pagdagdag ng bagong project
1. Gumawa ng bagong folder sa root (e.g. `My-Project/`).
2. Ilagay ang `Code.gs`, `README.md`, at iba pang files doon.
3. I-update ang listahan sa itaas.
